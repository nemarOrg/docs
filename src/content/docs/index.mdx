## What is NEMAR?

NEMAR (Neuroelectromagnetic Data Archive and Tools Resource) is a platform for archiving,
sharing, and processing neuroimaging datasets in Brain Imaging Data Structure (BIDS) format.
It is several systems working together: a website, a CLI, a backend API, a Zarr serving copy for
signal data, and a Model Context Protocol (MCP) server for AI assistants. If you are not sure
which of those you want, start with [Which surface should I use?](/ecosystem/which-surface/).
